# Security Policy

## Supported Versions

We release patches and security improvements on the latest `master` branch.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project and any contributed skills/MCP servers seriously.

If you discover a security vulnerability or sensitive data exposure:

1. **Do not create a public issue.**
2. Please report the issue privately using [GitHub Security Advisories](https://github.com/navigotechsolutions-labs/claude-agent-skills-hub/security/advisories/new).
3. Alternatively, email the maintainers directly at `security@navigotechsolutions.com`.
4. Please include:
   - A description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested mitigation or fix (if available)

### Response Timeline
- **Acknowledgement**: Within 24 hours
- **Assessment & Triage**: Within 48 hours
- **Patch Release**: Within 7 business days depending on severity

Thank you for helping keep our open-source community safe!
