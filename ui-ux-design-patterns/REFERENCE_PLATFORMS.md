# 🌐 The 12 Premier UI/UX Design Inspiration Libraries

A deep-dive index of the world's most valuable design reference libraries for mobile and web developers building UIs with AI.

---

### 1. 📱 Mobbin
* **URL:** [mobbin.com](https://mobbin.com)
* **Specialty:** The undisputed industry gold standard for mobile (iOS & Android) and Web design pattern teardowns.
* **Key Features:**
  - 300,000+ real production screenshots from 1,000+ top apps.
  - Granular flow categorization: Onboarding, Checkout, Authentication, Upgrade, Search, Settings.
  - Filter by UI element, UX pattern, and industry vertical (Fintech, Health, Social, SaaS).
* **When to Reference:** When architecting complete user journeys or multi-step mobile/web screens.

---

### 2. 💻 Refero Design
* **URL:** [refero.design](https://refero.design)
* **Specialty:** Curated real-world Web and SaaS UI design patterns.
* **Key Features:**
  - 40,000+ web page references from leading modern tech brands (Linear, Raycast, Vercel, Supabase).
  - Searchable by specific web page sections: Hero sections, Feature grids, Pricing matrices, Navigation bars, Footers.
  - Video interaction capture for complex web animations.
* **When to Reference:** When crafting modern marketing sites, SaaS product shells, or B2B web applications.

---

### 3. 📸 Appshots
* **URL:** [appshots.design](https://appshots.design)
* **Specialty:** Clean, high-resolution mobile app screenshot library.
* **Key Features:**
  - Fast visual browsing of trending iOS and Android interfaces.
  - Focuses on aesthetic typography, color themes, and modern card components.
* **When to Reference:** For quick visual palette inspiration and card layout ideas.

---

### 4. ⚡ 60fps Design
* **URL:** [60fps.design](https://60fps.design)
* **Specialty:** Interactive micro-animations, physics-based motion, and transitions in top mobile apps.
* **Key Features:**
  - High-frame-rate screen recordings capturing delicate gestures, sheet drags, and tactile haptic cues.
  - Demonstrates spring physics curves, exit/entry transitions, and morphing layout states.
* **When to Reference:** When building interactive components with Framer Motion, GSAP, or CSS animations.

---

### 5. 🔍 UI Sources (ScreensDesign)
* **URL:** [screensdesign.com](https://screensdesign.com)
* **Specialty:** In-depth user journey teardowns and growth UX breakdowns.
* **Key Features:**
  - Deep-dive audits into consumer app onboarding, conversion funnels, and retention hooks.
  - Teardowns of why specific UX patterns increase conversion and reduce churn.
* **When to Reference:** For growth hacking, onboarding UX optimization, and referral loop design.

---

### 6. 🎨 Chamjo Design
* **URL:** [chamjo.design](https://chamjo.design)
* **Specialty:** Korean and Asian digital product UI references.
* **Key Features:**
  - Masters of high-density information layout (super-apps, e-commerce, banking).
  - Exceptional typography pairing with mixed script and complex information hierarchies.
* **When to Reference:** When building high-density dashboards, e-commerce stores, or internationalized interfaces.

---

### 7. 🎬 Page Flows
* **URL:** [pageflows.com](https://pageflows.com)
* **Specialty:** Screen recordings of real user flows on desktop and mobile web.
* **Key Features:**
  - Step-by-step videos of signing up, inviting teammates, exporting reports, or upgrading plans.
  - Reveals defensive UI details: validation states, error banners, and edge cases.
* **When to Reference:** To ensure you don't miss edge cases and error states in multi-step workflows.

---

### 8. 🦙 Appllama
* **URL:** [appllama.io](https://appllama.io)
* **Specialty:** Mobile UI patterns and component teardowns.
* **Key Features:**
  - Visual catalog of mobile components (tab bars, search headers, modals, list items).
* **When to Reference:** For component-level mobile UI specifications.

---

### 9. 📈 Asoinspo
* **URL:** [asoinspo.com](https://asoinspo.com)
* **Specialty:** App Store screenshot design, icon design, and mobile paywalls.
* **Key Features:**
  - High-converting visual hierarchy, benefit-driven value propositions, and paywall templates.

---

### 10. 📦 Collect UI
* **URL:** [collectui.com](https://collectui.com)
* **Specialty:** Daily UI inspiration categorized by 167+ specific component types.
* **Key Features:**
  - Deep categorization: Modals, 404 pages, Checkout forms, User profiles, Activity feeds, Calendars, Audio players.
* **When to Reference:** When you need immediate inspiration for one specific component.

---

### 11. 🎯 Spottedinprod
* **URL:** [spottedinprod.com](https://spottedinprod.com)
* **Specialty:** Real, unedited user interface quirks and clever micro-interactions spotted live in production.
* **Key Features:**
  - Highlights delightful UX details, micro-copy gems, and creative problem-solving in production apps.
* **When to Reference:** For adding delight, polish, and senior-level UX touches to standard features.

### 12. 📐 Pttrns
